# samples/

Сюда положи **реальные письма Preply** в формате `.eml` — по ним пишется парсер.

Как получить в Gmail: открыть письмо → меню «⋮» → **Показать оригинал** →
**Скачать сообщение**.

Нужны три штуки:

| Файл | Событие |
|---|---|
| `booked.eml` | новый урок забронирован |
| `rescheduled.eml` | урок перенесён |
| `cancelled.eml` | урок отменён |

Если есть — добавь также письмо про пробный урок и про пакет из нескольких уроков
(`trial.eml`, `package.eml`): у них другая структура, и парсер должен уметь
возвращать несколько событий из одного письма.

Имя ученика можно заменить на вымышленное. **Не трогай** заголовки письма,
адрес отправителя, вёрстку и формат даты — именно за них цепляется парсер.

Эта папка целиком в `.gitignore`: письма содержат персональные данные учеников.
Обезличенные фикстуры для снапшот-тестов лежат отдельно, в
`tests/fixtures/emails/`, и коммитятся в репозиторий.
